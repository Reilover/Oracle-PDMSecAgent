## 5. 与论文表述的偏差清单（供论文会话回填）

1. **§4 "Rules are a fast path for the known, not a decision layer for the unknown"**：D1 实测规则层在 normal_ops benign 窗上 101/101 全部误判为攻击（假阳性率 100%），规则层从"快路径"变成"主要误差源"（对系统 tactic 的负贡献 ≈ −0.10 绝对值）。§4.3 该句需要限定或引用 A3b 消融数字改写。
2. **§6 单模型 0.850/0.629 vs D1 系统 0.554/0.437**：论文目前未声称系统级精度（占位"D1 measurement"），回填时**不能**表述为系统优于/接近单模型；必须给出规则层假阳性分解，否则审稿人会质疑串联收益。
3. **§4 "escalation moves a window along the accuracy–cost frontier"**：在 D1 的 231 个升级窗上，tier2 tactic 0.671 < tier1 0.689——升级在 tactic 维度是净负（+exact 0.520 vs 0.515 微正）。该句需弱化为"补充判别/人工证据"口径或引 D2 四象限归因。
4. **τ 扫描甜点**：论文若引用 20 窗预扫描结论，全量 439 窗支持 τ=0.75-0.80 为带宽甜点（auto 81%/76%，tactic 损失 ≤0.022）。
5. **延迟**：端到端 P50 1061ms（CPU 口径 tier1 主导）；论文引用时须带 CPU/GPU 双口径脚注（B1-2 补 GPU 后回填）。
