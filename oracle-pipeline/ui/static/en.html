ORACLE Tier-3 Console (BS-architecture prototype)

FastAPI (8024) replays audit.jsonl (append-only single source of truth) + writes human decisions back + SSE push; no database / no build step. The three human decision rights correspond to paper §4.2 Tier-3: ① per-question approve / veto / relabel + window-level confirm (queue → window detail) ② labeling of ambiguous windows (labeling page) ③ τ / τ_h threshold adjustment (dashboard sliders). Every decision is appended to audit.jsonl as a new event type.

API docs: /api/docs · SSE: /api/stream · Queue: /api/queue · Window detail: /api/window/{id}
